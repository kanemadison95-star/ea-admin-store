Installation

General setup steps for KairoX and AG Prime on MetaTrader 5.

1

Place the EA file

Copy the provided .ex5 file into MT5's MQL5/Experts folder (File → Open Data Folder).

2

Refresh the Navigator

Right-click "Expert Advisors" in the Navigator panel and refresh so the EA appears.

3

Attach to a chart

Drag the EA onto the correct chart and symbol for your license.

4

Enable Algo Trading

Turn on Algo Trading in the toolbar and allow it in the EA's Common tab.

5

Load your .set file

In the Inputs tab, load the provided .set configuration file if supplied.

6

Enter your license key

Paste the license key you received into the EA's License input.

7

Check Experts & Journal

Confirm the EA initialized correctly with no errors in these tabs.

8

Keep MT5 running

The EA only works while MT5 is open and connected — a VPS keeps it running 24/5.
